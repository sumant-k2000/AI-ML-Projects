# Face Recognition using CNN (LFW Dataset)

## Objective

Develop a Convolutional Neural Network (CNN) to recognize individuals using the Labeled Faces in the Wild (LFW) dataset.

---

## Dataset

Labeled Faces in the Wild (LFW)

Dataset Source:
https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_lfw_people.html

---

## Libraries Used

- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn
- Seaborn

---

## Methodology

1. Load the LFW dataset.
2. Normalize image pixel values.
3. Encode class labels.
4. Split the dataset into training and testing sets.
5. Build a CNN model using convolutional, pooling, flatten, and dense layers.
6. Train the model for 10 epochs.
7. Evaluate the model using accuracy, confusion matrix, and classification report.
8. Visualize training performance using accuracy and loss graphs.

---

## Results

- Successfully recognized faces using a CNN model.
- Achieved good classification accuracy on the test dataset.
- Demonstrated the effectiveness of CNNs for face recognition tasks.

---

## Conclusion

The CNN model effectively recognized individuals from the LFW dataset by learning important facial features automatically. The project demonstrates the practical application of deep learning techniques in face recognition and computer vision.
