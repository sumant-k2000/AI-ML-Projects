# Cancer Detection using MRI Images (CNN)

## Objective

Develop a Convolutional Neural Network (CNN) to detect brain tumors from MRI images.

---

## Dataset

Brain MRI Images for Brain Tumor Detection

Dataset Link:
https://www.kaggle.com/datasets/navoneel/brain-mri-images-for-brain-tumor-detection

---

## Libraries Used

- TensorFlow
- Keras
- NumPy
- OpenCV
- Matplotlib
- Scikit-learn
- Seaborn

---

## Methodology

1. Load the MRI image dataset.
2. Resize all images to 128×128 pixels.
3. Normalize image pixel values.
4. Encode the class labels.
5. Split the dataset into training and testing sets.
6. Build a CNN model using convolutional, pooling, flatten, and dense layers.
7. Train the model for 10 epochs.
8. Evaluate the model using test accuracy, confusion matrix, classification report, and performance graphs.

---

## Results

- Successfully classified MRI images into tumor and non-tumor classes.
- Achieved good classification accuracy on the test dataset.
- Demonstrated the effectiveness of CNNs for medical image analysis.

---

## Conclusion

The CNN model successfully detected brain tumors from MRI images by automatically learning meaningful image features. This project demonstrates the practical application of deep learning in medical diagnosis and computer vision.
