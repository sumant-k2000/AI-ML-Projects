# Adult Census Income Classification using Logistic Regression

## Objective

Develop a Logistic Regression model to predict whether an individual's annual income is above or below $50K using demographic and employment-related information.

---

## Dataset

Adult Census Income Dataset

Source:
https://www.kaggle.com/datasets/rdcmdev/adult-income-dataset

---

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## Methodology

1. Load the Adult Census Income dataset.
2. Display the first five records and dataset information.
3. Check and handle missing values.
4. Encode categorical variables using LabelEncoder.
5. Split the dataset into training and testing sets (80:20).
6. Train a Logistic Regression model.
7. Predict income classes on the test dataset.
8. Evaluate the model using Accuracy, Confusion Matrix, and Classification Report.

---

## Results

- Successfully classified individuals into income categories.
- Achieved good prediction accuracy using Logistic Regression.
- The confusion matrix and classification report indicate effective model performance.

---

## Conclusion

The Logistic Regression model effectively predicts whether an individual's annual income exceeds $50K. Proper preprocessing and feature encoding improved the model's performance. This project demonstrates the usefulness of machine learning for income prediction and binary classification tasks.
