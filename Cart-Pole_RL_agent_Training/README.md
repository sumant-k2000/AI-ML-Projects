# Cart-Pole RL Agent Training

## Objective

Develop a Reinforcement Learning agent using the Q-Learning algorithm to balance a pole on a moving cart in the CartPole-v1 environment.

---

## Environment

CartPole-v1 (Gymnasium)

Environment Documentation:
https://gymnasium.farama.org/environments/classic_control/cart_pole/

---

## Libraries Used

- Gymnasium
- NumPy
- Matplotlib

---

## Methodology

1. Create the CartPole-v1 environment using Gymnasium.
2. Explore the observation and action spaces.
3. Train a random agent to understand baseline performance.
4. Implement the Q-Learning algorithm using a Q-table.
5. Train the agent over multiple episodes.
6. Evaluate the trained agent using average rewards.
7. Visualize the training and evaluation rewards.

---

## Results

- Successfully trained a Q-Learning agent for the CartPole environment.
- The trained agent achieved higher rewards than a random agent.
- Demonstrated the effectiveness of Reinforcement Learning in sequential decision-making tasks.

---

## Conclusion

The Q-Learning agent successfully learned to balance the pole by maximizing cumulative rewards through interaction with the environment. The project demonstrates the practical application of Reinforcement Learning for control problems and intelligent decision-making.
