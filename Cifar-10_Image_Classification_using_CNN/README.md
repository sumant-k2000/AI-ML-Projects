# CIFAR-10 Image Classification using CNN

## Objective

Develop a Convolutional Neural Network (CNN) to classify images from the CIFAR-10 dataset into ten different object categories.

---

## Dataset

CIFAR-10 Dataset

Dataset Link:
https://www.kaggle.com/datasets/swaroopkml/cifar10-pngs-in-folders

---

## Libraries Used

- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn
- Seaborn

---

## Methodology

1. Load and preprocess the CIFAR-10 dataset.
2. Normalize image pixel values.
3. Build a CNN model with convolutional, pooling, flatten, and dense layers.
4. Train the model for 10 epochs.
5. Evaluate the model using test accuracy, confusion matrix, and classification report.
6. Visualize training performance using accuracy and loss graphs.

---

## Results

- Successfully classified images into ten categories.
- Achieved high training accuracy with satisfactory test performance.
- CNN effectively learned image features for classification.

---

## Conclusion

The CNN model demonstrated strong performance in classifying images from the CIFAR-10 dataset. The project highlights the effectiveness of deep learning in computer vision and image recognition tasks.
